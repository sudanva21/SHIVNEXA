# Shivnexa Industries — Industrial Safety Precision & Protective Equipment

> Official web platform for **Shivnexa Industries Pvt. Ltd.** — Providing certified industrial safety tools, heavy-duty protective equipment, and compliance safety systems for manufacturing, construction, utilities, and high-risk work environments across India.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v3](https://tailwindcss.com/) + Custom Industrial Design System
- **Components & Animation**: [Lucide React](https://lucide.dev/), [Framer Motion](https://www.framer.com/motion/), [Radix UI](https://www.radix-ui.com/)
- **Icons**: Material Symbols Outlined & SVG brand icons
- **Hosting**: Optimized for [Vercel](https://vercel.com/) (configured via `vercel.json`)

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```

---

## 🌐 Deploy to Vercel

This repository includes a pre-configured `vercel.json` with single-page application (SPA) routing rewrites.

1. Import this repository in [Vercel Dashboard](https://vercel.com/new).
2. Framework Preset will auto-detect as **Vite**.
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**.
